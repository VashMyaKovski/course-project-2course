## Быстрый старт

Клонирование:
```shell
git clone https://github.com/VashMyaKovski/course-project-2course.git
cd course-project-2course
```

Установка:
```shell
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

Конфигурация:
```shell
cp .env.dev .env # Отредактируйте .env!!
```

Запуск:
```shell
python src/main.py
```

## Для разработчиков

Перед каждым пушем использовать isort и black для python-файлов. Это необходимо для поддержания правильного вида кода.

```shell
isort . # Вместо точки можно использовать любой другой путь, по которому нужно проверить файлы на форматирование
black .
```

В ближайшем будущем планируется сделать прекоммиты.
